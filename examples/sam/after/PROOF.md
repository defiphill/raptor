# Proof

A fresh agent (a smaller, cheaper model than the one that built it) got only `brain/AGENTS.md` and four requests. It could read only what the entry routed it to.

| Request | Routed to | Rules it applied | Result |
|---|---|---|---|
| "Here are my call notes from Fernway, make the brief." | client-work + brief-structure skill | five sections, no solutions, draft only, weekly rate | Pass |
| "Tighten this draft for Thursday." (#48) | newsletter | edit not rewrite, 900 words, no em dashes or banned phrases, British spelling, 3 subject lines | Pass |
| "Critique these three screens." | critique | ranked by impact, hierarchy and spacing, blunt | Pass |
| "What's next on the Fernway case study?" | State → projects/fernway.md | handoff: Outcome section and image list next | Pass |

4 of 4 routed to the right agent with the right rules, opening 8 files out of the whole brain.

What it caught that the build got wrong: `State.md` lists Fernway as "Live", but a case study is written after a project ends. A weekly trim would flag this; it is left as built so the example stays an honest run.
