# brief-structure
Trigger: call notes to turn into a brief, or a finished project to write up.
Steps: write these sections in order, short bullets, no solutions.
1. Problem 2. Users 3. Constraints 4. Success 5. Open questions
Case study: same five, then Outcome and an image list.
Acceptance: all sections present, no "solutions" section, problem has a number when the notes have one.
